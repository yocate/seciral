# SECIral (セキラル)

## プロジェクト名称の由来
- **由来**: **SECI**モデル (暗黙知と形式知の変換プロセス) ＋ **Spiral**（らせん・循環）
- **響き**: 「赤裸々（せきらら）」にも近く、オープンに知識を共有し合うカルチャーを連想させます。組織のナレッジを包み隠さずオープンにし、循環させることで価値を生み出すプラットフォームを目指しています。

## 1. プロダクト概要
SECIral (旧称: Strategy Intelligence Platform / SIP) は、属人化しやすい「戦略立案」や「アイディア創出」のプロセスを、生成AIとナレッジグラフの力で形式知化し、組織全体の思考を拡張するAI伴走型のプラットフォームです。

最新のビジネスフレームワークをAIが使いこなし、ユーザーの壁打ち相手として機能するとともに、対話から生まれた「思考の連鎖」を抽出・構造化して蓄積します。使うほどに組織固有のナレッジが成長し、点在していた情報が線（因果ループ）として結びつき、より高次元な戦略決定を支援します。

## 2. コアとなる理論・アプローチ

SIPは、以下の学術的・実践的アプローチを融合させた独自のアーキテクチャに基づいています。

### 2.1. System Dynamics (システムダイナミクス) と Causal Loop Diagram (因果ループ図)
事象を単発の出来事（点）としてではなく、相互に影響を及ぼし合う循環的な構造（ループ）として捉える理論です。
SIPでは、文書やチャットの履歴から「Aが増えるとBが減る」「Bが減るとCが増える」といった因果関係をAIが抽出し、組織のシステム力学を因果ループ図（CLD）として可視化します。これにより、「自己強化ループ（好循環・悪循環）」や「バランスループ（抵抗勢力）」を直感的に発見できます。

### 2.2. Temporal Knowledge Graph (時間的制約を持つナレッジグラフ)
静的なナレッジグラフではなく、「いつの時点での知見か（valid_from / valid_to）」を保持するTemporal Knowledge Graphを採用しています。戦略や市場環境は常に変化するため、最新のコンテキストに基づいた推論（RAG）を可能にすると同時に、「なぜこの意思決定が過去に行われたか」という経緯のトラッキングを実現します。

### 2.3. GraphRAG (Graph Retrieval-Augmented Generation)
単純なベクトル検索（セマンティック検索）によるRAGの限界を克服するため、グラフ構造を用いたRAG（GraphRAG）を実装しています。ノード（概念）間のエッジ（因果や関連）を辿ることで、「市場縮小が採用難にどう影響しているか」といった、複数ドキュメントに跨る複雑な因果関係の問いに対して高精度に回答します。

### 2.4. 戦略フレームワークの統合
SWOT分析、PEST分析、3C分析などのビジネスフレームワークをAIの「思考の型（スキーマ）」として提供します。ユーザーがフレームワーク名を知らなくても、対話を通じて自然にこれらのレンズを通して情報が整理・抽出されるよう設計されています。

## 3. 主な機能
- **Diagnostic Session (診断チャット)**: ユーザーとAIによる壁打ち機能。会話の中から自動で因果関係や重要概念を抽出します。
- **Knowledge Ingestion (ナレッジ取り込み)**: 既存のPDFやMarkdown文書をアップロードし、テキスト抽出・要約・ベクトル化・グラフ抽出を非同期で実行します。
- **Causal Loop Visualization (因果ループ可視化)**: 組織のナレッジグラフから因果ループ（最大4ノードの循環構造）を自動探索し、Force-directed graphでアニメーション表示します。
- **Deliverable Review (成果物レビュー)**: ユーザーが作成したドキュメントを、組織の最新ナレッジグラフと照らし合わせ、「矛盾」や「考慮漏れ（死角）」がないかをAIがレビューします。

## 5. 環境構築・起動手順

本プロジェクトはフロントエンド（React/Vite）とバックエンド（FastAPI/Python）に分かれています。以下の手順でローカル環境を構築してください。

### 前提条件
- Node.js (v18以降を推奨)
- Python (3.10以降を推奨 ※現在3.14環境で構築実績あり)
- Git

### ステップ 1: リポジトリのクローン
```bash
git clone https://github.com/yocate/seciral.git
cd seciral
```

### ステップ 2: バックエンドのセットアップ
バックエンドディレクトリに移動し、Pythonの仮想環境を構築します。
```bash
cd backend
python3 -m venv .venv
source .venv/bin/activate
```

依存パッケージをインストールします。
```bash
pip install -r requirements.txt
```

環境変数を設定します。`.env.example` をコピーして `.env` を作成し、Google Gemini APIキーを設定してください。
```bash
cp .env.example .env
# .env ファイルを開き、GEMINI_API_KEY=あなたのAPIキー に書き換えてください
```

FastAPIサーバーを起動します。
```bash
uvicorn main:app --host 0.0.0.0 --port 8000 --reload
```
（サーバーは `http://localhost:8000` で起動します）

### ステップ 3: フロントエンドのセットアップ
別のターミナルタブを開き、フロントエンドディレクトリに移動します。
```bash
cd frontend
```

依存パッケージをインストールします。
```bash
npm install
```

Vite開発サーバーを起動します。
```bash
npm run dev
```
（デフォルトで `http://localhost:5173` で起動します）

ブラウザで `http://localhost:5173` にアクセスし、SECIralの画面が表示されれば環境構築は完了です。
